 Vaccination Record Console System
Project Overview
This project is a Java console application that manages vaccination records. It allows users to register patients, record vaccinations, and view stored information through a simple menu-driven interface.
The system demonstrates core Object-Oriented Programming (OOP) principles such as encapsulation, inheritance, and abstraction.

Domain Context
This system is based on a healthcare environment where clinics or hospitals need to track patient vaccinations.
This application simulates a simplified version of such a system by:
•	Storing patient details
•	Recording vaccination events
•	Managing vaccine-related information

 How to Compile and Run
1.	Navigate to the project root folder
2.	Compile all Java files:
3.	javac csi142/model/*.java csi142/data/*.java csi142/app/*.java
4.	Run the application:
5.	java csi142.app.MainApp

Using VS Code
1.	Open the project in VS Code
2.	Ensure all packages are correctly structured:
o	csi142.model
o	csi142.data
o	csi142.app
3.	Run MainApp.java

Feature Summary
•	Patient Registration
o	Add new patients with ID, name, age, and contact details
•	View Patients
o	Display all registered patients
•	Add Vaccination Record
o	Record vaccine name and date for a patient
•	View Vaccination Records
o	Display all recorded vaccinations
